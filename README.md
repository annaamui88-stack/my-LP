Anna Amui — Landing Page Premium

Website resmi Anna Amui, brand manisan mangga khas Indramayu yang ditujukan untuk masyarakat Indonesia di luar negeri, dengan fokus utama WNI/PMI di Hong Kong dan Taiwan.

Website dirancang dengan pendekatan mobile-first, SEO-friendly, ringan, dan conversion-oriented, dengan pemesanan melalui WhatsApp.

🔗 Strategi Internal Linking

Artikel tidak dibuat berdiri sendiri.

Setiap artikel sebaiknya memiliki hubungan dengan artikel lain dan halaman utama.

Struktur sederhananya:

                 BERANDA
                    │
          ┌─────────┴─────────┐
          │                   │
       PAKET                BLOG
          │                   │
          │          ┌────────┼────────┐
          │          │        │        │
          │       Artikel 1 Artikel 2 Artikel 3
          │          │        │        │
          │       Artikel 4 Artikel 5 Artikel 6
          │          │        │        │
          │       Artikel 7 Artikel 8 Artikel 9
          │                   │
          │               Artikel 10
          │
       PESAN

Tujuannya agar Google lebih mudah memahami hubungan antara:

Indramayu → mangga → manisan mangga → WNI/PMI → Hong Kong → Taiwan → produk Anna Amui.

📈 Strategi SEO Konten

Tahap awal website menggunakan 10 artikel utama sebagai fondasi topical authority.

Artikel diarahkan untuk menjawab berbagai kebutuhan pencarian pengguna, bukan hanya menjual produk.

Prinsip konten:

«Berikan informasi terlebih dahulu, bangun kepercayaan, kemudian arahkan pembaca menuju produk.»

Setiap artikel idealnya memiliki:

- 1 keyword utama
- beberapa keyword pendukung
- heading H2/H3 yang jelas
- internal link
- link menuju halaman produk jika relevan
- meta description
- canonical
- Open Graph
- Schema BlogPosting
- gambar dengan alt text relevan

---

Setelah 10 artikel utama selesai, konten dapat dikembangkan menjadi cluster yang lebih spesifik.
