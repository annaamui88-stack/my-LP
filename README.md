# 🥭 Anna Amui - Landing Page Premium

Landing Page resmi brand **Anna Amui**, menjual Manisan Mangga Khas Indramayu dengan target pasar Pekerja Migran Indonesia (WNI) di Hong Kong.

## 🚀 Fitur Utama
- **Pure Native Stack**: HTML5, CSS3 Modern, & JavaScript ES6 (Tanpa Framework).
- **Mobile First & Responsive**: Tampilan responsif optimal di Smartphone, Tablet, & Desktop.
- **WhatsApp Direct Order**: Konversi penjualan via integrasi link WhatsApp.
- **Conversion-Oriented UI/UX**: Inspirasi dari Apple, Grab, Gojek, dan Shopify.
- **Lengkap SEO & Schema**: Siap untuk performa Google Search Engine.
